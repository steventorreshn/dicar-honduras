# Dicar Honduras — Demo de sitio web

Propuesta de sitio web para **Dicar**, especialistas en frenos en Honduras.

**Ver la demo:** https://steventorreshn.github.io/dicar-honduras/

- Sitio de una sola página: HTML, CSS y JavaScript, sin dependencias.
- Animaciones de scroll, catálogo con filtros, marcas, galería de la bodega y asesores por región.
- Formulario de cotización que envía el mensaje por WhatsApp al asesor de la región elegida.
